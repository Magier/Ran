[Implementations](https://github.com/DataDog/stratus-red-team/tree/d5d25aba6f338933911002f186d238bf175d5d3a/v2/internal/attacktechniques/k8s)

All procedures are implemented using the [Go client for Kubernetes](https://github.com/kubernetes/client-go). The `k` command in The `Procedure` column should be read as an alias for that client, which results in the same API request to the API server.
