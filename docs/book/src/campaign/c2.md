# The C2 Layer

Ran routes commands through execution channels known to the campaign. Kubernetes exec is the normal initial channel. The Rust runtime also supports persistent reverse-shell sessions.

The enabled `create-listener` TTP starts a TCP listener. When a reverse shell connects, Ran registers the live session against its target so later commands can use that channel. Session liveness and command framing are handled by the Rust C2 runtime.

Sliver RPC is not implemented. Sliver-specific TTP definitions are retained only as disabled design sketches and cannot become applicable. A future Sliver backend will be native Rust code with a newly designed integration boundary.

WebSocket RPC is also not a current transport. API requests use REST, live browser updates use SSE at `/events`, and future WebSocket RPC will use a new protocol rather than a retired wire format.
